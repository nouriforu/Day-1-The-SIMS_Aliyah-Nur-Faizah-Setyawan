**Pemaparan STUPEN, PBL & Magang** (Kak Hanif = moderator)

**STUPEN = MBKM (Merdeka Belajar Kampus Merdeka), 2020**
- Tujuan utama: lulus siap kerja dan relevan dengan kebutuhan industri.
- Kegiatan di luar kampus dikonversi menjadi SKS.
- Pembelajaran fleksibel.
- Ketentuan: 2 semester, 20 SKS, 8 bentuk kegiatan.


**MSIB = program unggulan**
-  Bersertifikat
- Bersama mitra industri dan organisasi terkait
- Berlangsung 1 semester

**8 bentuk kegiatan:**
- Pertukaran pelajar
- Magang
- Asistensi mengajar
- Penelitian/riset
- Proyek kemanusiaan
- Kegiatan wirausaha
- Proyek independen
- KKN

**Rencana per semester:**
- Semester 5: Stupen di industri
- Semester 6: Presentasikan hasil Stupen ke kampus
- Semester 7: Magang

**Project Based Learning**
Belajar lewat karya nyata, berupa produk, prototipe, atau aplikasi.

**Problem Based Learning**
Belajar memecahkan masalah, mencari informasi dan merumuskan solusi. Dosen berperan sebagai fasilitator.

**Case Based Learning**
1. Pelajari kasus
2. Identifikasi masalah
3. Analisis
4. Rumuskan solusi
5. Presentasikan

5. Jalani & konversi SKS
